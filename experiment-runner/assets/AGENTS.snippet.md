## Experiments

Before running any experiment, training run, benchmark, or simulation, use the `experiment-runner` skill: the working tree must be clean (ask the user whether to commit, stash, or discard pending changes; never decide alone), the run must be registered with its commit hash in `experiments/LOG.md`, linked to its `H-xxx / T-xxx` entry in `HYPOTHESES.md`, and closed with the observed results.
